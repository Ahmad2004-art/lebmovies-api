 LebMovies API

Backend REST API for a movie platform built with **Node.js**, **Express**, and **MySQL**.

   Features
- User authentication (JWT)
- Role-based access (Admin / User)
- Movies CRUD operations
- User profiles & admin panel
- Secure password hashing (bcrypt)
- File uploads (Multer)

  Tech Stack
- Node.js
- Express.js
- MySQL
- JWT, bcrypt
- HTML, CSS, JavaScript

  Run Locally
```bash
cd lebmovie/lebmovie/backend
npm install
node server.js
